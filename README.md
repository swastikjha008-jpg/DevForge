# 🚀 Overview

**DevForge** is an AI-powered project generator that transforms natural language prompts into production-ready starter projects.

Instead of spending hours creating folders, configuring dependencies, writing boilerplate code, and setting up project architecture, simply describe what you want to build and let DevForge generate a clean foundation for your next application.

Whether you're building your next side project, MVP, hackathon submission, or learning a new stack, DevForge helps you start faster.

# 🚀 Getting Started

## 1️⃣ Clone the Repository

```bash
git clone https://github.com/yourusername/devforge.git
```

```bash
cd devforge
```

---

## 2️⃣ Install Dependencies

```bash
pnpm install
```

---

## 3️⃣ Configure Environment Variables

Create a `.env` file inside the backend.

```env
GEMINI_API_KEY=YOUR_API_KEY
PORT=5000
NODE_ENV=development
```

---

## 4️⃣ Start Development

```bash
pnpm dev
```
